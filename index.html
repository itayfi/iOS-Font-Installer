  1. Prepare the profile, then tap Install profile.
  2. Allow Safari to download the configuration profile.
  3. Open Settings and tap Profile Downloaded, then follow the installation prompts.
Note: Installed fonts are available only in apps that support custom fonts. This does not change the iOS system font.
